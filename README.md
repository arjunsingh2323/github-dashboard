# GitHub Profile & Repo Dashboard

A vanilla JavaScript project that fetches and displays GitHub user profiles and repositories using the public GitHub API — no frameworks, no backend.

## Features
- Search any GitHub username to view their profile and public repositories
- Filter repositories by programming language
- (Coming soon) Pin favorite repos to a personal dashboard, saved locally
- (Coming soon) Debounced live search and form validation

## Built With
- HTML, CSS, JavaScript (no frameworks)
- [GitHub REST API](https://docs.github.com/en/rest)

## Concepts Practiced
- DOM manipulation and event handling
- Array methods: `map`, `filter`, `forEach`, `find`
- Async JavaScript: `fetch`, Promises, `async`/`await`
- `localStorage` and JSON persistence
- Debouncing, form validation, and error handling
